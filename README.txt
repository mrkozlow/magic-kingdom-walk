MAGIC KINGDOM 3-MILE GPS AUDIO WALK

Open index.html in a supported browser/web host.

Placeholder audio:
- All seven area tracks are original synthetic placeholders created for this prototype.
- They are included in the audio/ folder and load automatically.
- To replace a track while the page is open, tap its “Replace audio” button and choose your own audio file.

Permanent replacement:
If you later host/edit this folder, replace the matching MP3 in audio/ while keeping these filenames:
  entrance.mp3
  mainstreet.mp3
  tomorrowland.mp3
  fantasyland.mp3
  liberty.mp3
  frontierland.mp3
  adventureland.mp3

GPS note:
Mobile browsers normally require a secure HTTPS page for geolocation. The app itself is self-contained, but for real GPS use it should be served over HTTPS rather than merely opened as a local file.
